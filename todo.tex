Simulation + validation
Run 10,000–100,000 random games.
Assert:
exactly 32 cards played;
exactly eight tricks;
exactly 120 Augen;
no illegal moves;
no duplicate cards;
no hidden information leaks;
reproducibility with seeds.
This is particularly valuable before training anything, because an RL agent will exploit bugs in the environment mercilessly.
